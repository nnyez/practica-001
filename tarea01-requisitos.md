# Tarea 01: Ingeniería de características

## Requisitos

### Dataset

Se debe presentar el dataset identificado e indicar si es público o si fue construido para la tarea. También se debe incluir la URL del dataset y especificar si fue modificado. Si se realizaron modificaciones, se debe explicar qué cambios se hicieron.

### Análisis exploratorio y visualizaciones

El análisis exploratorio debe incluir imágenes relacionadas con los datos. Se deben mostrar las categorías de productos más importantes y elaborar figuras que representen el comportamiento de las compras a lo largo del tiempo.

Las imágenes deben organizarse semana a semana durante un período de dos meses. Este período permitirá visualizar mejor los cambios y demostrar si existe un patrón de compras. Para el análisis se debe realizar un muestreo de las categorías de productos.

También se deben incluir imágenes adicionales que permitan observar cómo evolucionan las compras en el tiempo y analizar si los feriados influyen en su comportamiento.

### Variables creadas

Se deben presentar y explicar las variables creadas durante la ingeniería de características. Entre ellas deben considerarse las variables relacionadas con los fines de semana y los feriados.

### Criterios del análisis y del reporte

Para determinar si el análisis se está realizando correctamente, las imágenes deben ser claras y mostrar un patrón reconocible. El reporte debe ser sencillo e intuitivo, y debe demostrar que se comprende el negocio y la información contenida en los datos.

Cada figura debe tener un título y debe identificar claramente los nombres de los ejes X e Y.

### Presentación final

Se debe preparar una presentación de aproximadamente cinco minutos. Las diapositivas deben incluir:

- La URL del dataset.
- La indicación de si el dataset es público o construido.
- Las modificaciones realizadas al dataset, si las hubo.
- Las variables creadas.
- Las categorías y los productos analizados.
- Las figuras con títulos y nombres en los ejes.

El resultado debe presentarse como un reporte profesional de ingeniería de características, no únicamente como un cuaderno de trabajo.
